# Agent 活动分类 Prompt（未过期全量）

> 与 `classification-pending.json` 配套。**禁止**用 `inferCategory` / JS 正则批量写库。

## 展示分类（`category`，只能取其一）

| 分类 | 适用 |
|------|------|
| **约饭** | 纯约饭局（抓取极少；App 用户自发） |
| **戏剧表演** | 脱口秀、话剧、魔术、舞台剧、沉浸式夜游剧 |
| **音乐现场** | 演唱会、音乐会、音乐节、Live |
| **市集** | 快闪、集市、啤酒节、动漫节/漫展/同人only、嘉年华；**公众可免费/购票逛的博览会**（茶博会、食博会、咖啡文化节等） |
| **体育运动** | 球类、竞技、体育赛事 |
| **户外活动** | 徒步、露营、溯溪、乡村一日游、Citywalk、登塔观景 |
| **主题沙龙** | 读书会、话题沙龙、破圈/跨职业/创业者交流、销售力沙龙、品鉴体验、绘画/演讲/舞蹈体验社交、桌游交友局 |
| **看展逛馆** | 博物馆/美术馆、特展、VR 沉浸展、摄影展、**艺术博览会** |
| **遛娃亲子** | 亲子乐园、动物园、儿童科普展、明确少儿向 |
| **其他** | **纯 B2B 行业展**（跨境招商、工业展、车展招商）、门票产品、明星见面会、商拍招募、系统培训课程 |

### 展会怎么分（重点）

| 类型 | 分类 | suggested |
|------|------|-----------|
| 公众可逛、免费领票/购票入场（茶博会、食博会、HOTELEX、同人only、动漫节） | **市集** 或 **看展逛馆**（艺术展） | `true` |
| 纯 B2B 招商（跨境电商交易会、工业自动化展、智慧监狱展等） | **其他** | `false` |
| 模特/演员招募、宠物乐园门票 | **其他** | `false` |

> **「其他」里不要堆公众博览会**——能逛的都归市集或看展逛馆。

> **已废弃（勿用）：** Coffee Chat、小酌、交友聚会、疗愈成长。

## 判断材料（必须综合）

每条读：`title`、`body_excerpt`、`detail_excerpt`、`location`、`douban_event_type`（仅供参考）、`slide_category`（仅供参考）。

## suggested（推荐 / 挡下）

- `true`：适合 Zup 线下结伴、娱乐、体验
- `false`：B2B 展会、行业博览、培训课、创业招商会等

挡下也须写 `category`（创业/B2B 用 **其他**；有主题的交流局用 **主题沙龙**）。

## 输出格式

写入同目录 `classification-decisions.json`：

```json
{
  "city": "深圳",
  "source": "douban",
  "decided_at": "2026-07-02T12:00:00.000Z",
  "agent": "cursor-composer",
  "decisions": [
    {
      "event_uid": "douban:123",
      "suggested": true,
      "category": "看展逛馆",
      "reason": "博物院文物特展，面向公众观展"
    }
  ]
}
```

**`decisions` 必须覆盖 pending 中每一条 `event_uid`，不得遗漏。**
