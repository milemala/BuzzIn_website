# 把审核台放到阿里云

每天自动发商户气泡，需要这台服务一直开着。家里电脑合上盖就会停，所以要放到一台不关机的云服务器上。

云上只跑审核台（商户审核、气泡发布，以及以后的每天定时发布）。抓豆瓣、小红书、大众点评仍然在你自己的电脑上做。

审核台页面本身没有登录密码。默认只允许在云服务器自己里面打开，不把端口暴露到公网。你在自己电脑上通过一条加密通道去看页面。

## 买哪台机器

阿里云控制台选 **轻量应用服务器**，不要选容器、函数计算或 Kubernetes。

- 系统：Ubuntu 22.04
- 规格：2 核 4G 就够
- 硬盘：40G 或更大。要拷过去的数据库和封面大约 1G
- 地域：选离你近的，比如上海或杭州
- 带宽：3Mbps 够用

买好后记下公网 IP，用控制台给的 root 密码登录。

## 在你自己电脑上打包

打开终端，进入 `zup-event-crawl` 目录，执行：

```bash
bash scripts/pack-cloud.sh
```

会生成 `zup-event-crawl/data/zup-review-cloud.tar.gz`。这个包带上现在的商户名单、已选商户和封面图，不带抓取缓存。

## 拷到云上并安装

把压缩包上传到服务器的 `/opt`（阿里云控制台的「远程连接」里可以用它提供的上传方式，或在你电脑上执行下面这句，把 IP 换成你的）：

```bash
scp zup-event-crawl/data/zup-review-cloud.tar.gz root@你的公网IP:/opt/
```

登录云服务器后执行：

```bash
mkdir -p /opt/zup-review
tar -xzf /opt/zup-review-cloud.tar.gz -C /opt/zup-review
bash /opt/zup-review/deploy/install-on-cloud.sh
```

安装脚本会装好 Node、依赖，并设置成开机自动启动。服务器重启后审核台也会自己起来。

## 在自己电脑上打开页面

云服务器上再开一个窗口，保持这条命令不要关：

```bash
ssh -L 8790:127.0.0.1:8790 root@你的公网IP
```

然后在你自己电脑的浏览器打开：

http://127.0.0.1:8790/merchant-bubbles.html

页面和现在一样。顶部环境选「正式」之后，操作的是线上后台。这条通道关掉，页面就打不开，但云上的服务还在跑。

## 以后怎么更新

在自己电脑上改完代码后，重新打包上传，在云上解压覆盖 `/opt/zup-review`，再执行：

```bash
systemctl restart zup-review
```

商户名单、文案池、已选商户都在云上的数据库里。部署之后，气泡相关的勾选和发布以云上这份为准。不要一边在家里电脑改名单、一边在云上发布，两份会各记各的。

## 和每天自动发布的关系

服务放到云上并一直开着之后，才能做「每天几点重复发布」。定时会记在这份云上的审核台里，到点自己发你已经启用的商户。这一步还没做，等服务器跑起来再加。
